# AppSales 隐私政策

生效日期：2026 年 9 月 29 日  
最近更新：2026 年 9 月 29 日

AppSales 重视你的隐私和数据安全。本隐私政策说明 AppSales 在你使用应用及其桌面小组件时，如何处理、存储和传输信息。

本政策所称“我们”或“AppSales 开发者”，是指负责提供和维护 AppSales 的开发者。AppSales 当前没有自建用户账号系统或业务数据服务器，不会把你的 App Store Connect 连接凭证或经营报表上传到由我们控制的服务器。

## 1. AppSales 处理的信息

为了提供 App Store Connect 报表查看、统计分析和桌面小组件功能，AppSales 会在你的设备上处理以下信息：

- App Store Connect 连接信息，包括 Key ID、Issuer ID、API 私钥和供应商编号。
- 你为连接配置的账号名称等本地标识。
- 从 App Store Connect 获取的销售、收入、下载、产品、地区、来源、财务和同步状态等经营数据。
- 应用设置，包括当前账号、筛选条件、显示范围、小组件刷新时间和会员权益缓存。
- 由 Apple StoreKit 提供并验证的 AppSales Pro 产品、购买状态和权益信息。

这些信息用于实现你主动使用的功能，不用于广告、跨应用跟踪、用户画像或向你发送营销信息。

## 2. 信息如何存储

### 2.1 连接凭证

Key ID、Issuer ID、API 私钥和供应商编号保存在 iOS 钥匙串中。钥匙串项目采用仅限当前设备的系统保护级别，并通过 App Group 对 AppSales 主应用和 AppSales 小组件开放，以便在获得系统调度时更新小组件数据。

连接凭证不会写入销售报表数据库，也不会上传到由我们控制的服务器。

### 2.2 报表和缓存

完整经营报表保存在应用专属目录的本地 SQLite 数据库中。数据库及相关缓存采用 iOS 文件保护，并被排除在设备备份之外。

AppSales 小组件仅在 App Group 容器中保存展示所需的精简汇总、显示设置和刷新状态，不会复制完整经营报表。

### 2.3 偏好设置

AppSales 使用系统提供的 UserDefaults 保存应用自身以及同一 App Group 内主应用和小组件共享的偏好设置。AppSales 不会读取其他开发者应用的偏好设置。

## 3. 网络请求和第三方服务

AppSales 只为提供你所使用的功能发起网络请求，且请求均使用 HTTPS。

### 3.1 Apple

AppSales 会直接连接以下 Apple 服务：

- App Store Connect API 和 Apple 提供的报表下载地址，用于验证连接并获取经营报表。
- Apple 的公开 App Store 查询、评分和排行榜接口，用于显示应用公开信息。
- Apple StoreKit，用于加载 AppSales Pro 产品、处理购买、恢复购买和验证会员权益。

访问 App Store Connect 时，AppSales 会在设备上使用你的 API 私钥签发短期访问令牌，并把完成请求所必需的令牌、账号标识、查询条件和报表请求发送给 Apple。Apple 对这些信息的处理受 Apple 的隐私政策及相关服务条款约束。

AppSales 不会接触你的银行卡号或完整付款资料。App 内购买由 Apple 处理。

### 3.2 Frankfurter 汇率服务

当你查看需要币种换算的金额时，AppSales 会向 `api.frankfurter.dev` 发送币种代码和日期范围，以获取公开的当前或历史汇率。AppSales 不会向该服务发送 App Store Connect 凭证、供应商编号、App 标识或经营报表内容。

和任何互联网请求一样，该服务及其网络基础设施可能接收到完成连接所需的网络信息，例如 IP 地址。此类信息由服务提供方按照其自身的运行和隐私规则处理；AppSales 开发者不会从该服务接收或保存你的 IP 地址。

## 4. 我们不会进行的活动

当前版本的 AppSales：

- 不包含第三方广告 SDK。
- 不包含第三方用户行为分析或崩溃统计 SDK。
- 不进行跨 App 或跨网站跟踪。
- 不出售或出租你的信息。
- 不把连接凭证或经营报表提供给广告商、数据经纪商或其他无关第三方。
- 不访问通讯录、位置、照片图库、相机或麦克风。

当你使用文件选择器导入 App Store Connect `.p8` 私钥时，AppSales 只读取你明确选择的文件。

## 5. 信息保留和删除

本地经营报表、设置和连接凭证会保留到你主动删除相关内容为止。

你可以在 AppSales 中：

- 使用“清除报表缓存”删除本机保存的经营报表，同时保留账号连接。
- 使用“移除账号与本地数据”删除相应账号的连接凭证、报表缓存和小组件数据。
- 在 Apple 后台撤销相应的 App Store Connect API 密钥，立即阻止该密钥继续访问 Apple 服务。

卸载 AppSales 会删除主应用及 App Group 容器中的数据库、报表和小组件缓存。按照 iOS 钥匙串的系统行为，钥匙串项目在卸载应用后可能继续保留在设备上。若你希望在卸载前删除连接凭证，请先在 AppSales 中使用“移除账号与本地数据”，并可同时在 App Store Connect 撤销 API 密钥。

AppSales 没有保存这些内容的开发者服务器，因此我们无法远程访问或代替你恢复、导出或删除设备上的本地数据。

## 6. App 内购买

AppSales Pro 的购买和恢复由 Apple StoreKit 处理。AppSales 仅读取经过 StoreKit 验证的产品和权益状态，以决定是否解锁相应功能。付款信息、Apple ID 和交易结算由 Apple 根据其隐私政策和服务条款处理。

## 7. 数据安全

AppSales 使用 iOS 钥匙串、App Group 权限、文件保护、原子写入和 HTTPS 等系统机制保护数据。API 私钥仅在设备上用于签发短期访问令牌。

尽管我们采取了合理的安全措施，但任何电子存储和网络传输方式都无法保证绝对安全。你应妥善保管 App Store Connect API 密钥，并在怀疑密钥泄露时立即前往 Apple 后台撤销密钥。

## 8. 儿童隐私

AppSales 面向管理 App Store Connect 业务数据的开发者和组织，不以儿童为目标，也不会有意收集儿童的个人信息。

## 9. 跨境处理

Apple 和 Frankfurter 可能在你所在国家或地区之外处理网络请求。相关处理地点和保护措施由各服务提供方决定。AppSales 开发者不运营用于接收连接凭证或经营报表的服务器。

## 10. 本政策的变更

当 AppSales 的功能、数据处理方式或适用规则发生变化时，我们可能更新本政策。更新后的政策会公布在 AppSales 的隐私政策页面，并修改页面顶部的“最近更新”日期。重大变化会在合理可行的情况下通过应用内说明或 App Store 版本说明告知你。
